Состав пользовательского пака должен быть такой:
custom/
 click.mp3      
 menu.mp3       
 game.mp3       
 auth.mp3       
 start.mp3      
 lclick.mp3
 rclick.mp3
 lose.mp3
 wow.mp3
 boom.mp3
 notification.mp3

Поддерживается рандомизирование треков - auth.mp3, menu.mp3, game.mp3, start.mp3
Для создания рандомизации треков исключите оригинальное название трека, и добавляйте треки с нумерацией в конце имени: game1.mp3, game2.mp3 и т.д.
При отсутствии трека программа возьмёт трек из пака classic
